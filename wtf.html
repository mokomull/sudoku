WTF is this?

This is a Sudoku solver specifically for how I, mokomull, have been manually solving them (and using auto-hints for the "challenging" difficulty).

How do I use it?

The UI is not intended to be intuitive, and since it's built just for myself, I just deal with the quirks. It's probably impossible to use without a mouse and keyboard, because I haven't gotten <body> keyboard events wired up yet.

User input:

  • Click on any square to focus on it.
  • Type a number 1-9 to set that cell to that value. Invalid choices will be rejected.
  • Press shift+number to see all of the places where that digit is a valid choice.
  • Press Ctrl+Z or ⌘Z to undo what you just did.
  • Hover over a hint in the bottom section to see what it'll do.
  • Click on a hint in the bottom section to apply it to the board.

Reading the UI:

  • Big numbers are "solved" cells; that is, their value is known or given and all conflicting allowable moves have been removed from the board.
  • Little numbers are the possible values that can go in that cell.
  • Below the board is a list of hints that have been deduced from the current state of the board. When hovering, cells are highlighted in
    • orange: the evidence from which the hint was deduced, and
    • green: the options that will be excluded from the board, should you choose to accept this hint.
